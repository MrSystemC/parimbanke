# Пар'ИМБА'нк — Автономный режим

Полностью рабочая версия без Cloudflare, Sites и внешних зависимостей.

## Запуск

```bash
node standalone/server.mjs
# или
npm run start:standalone
```

Откройте http://localhost:3000

**Демо-вход:**  
Email: `owner@local.test`  
Пароль: `demo123`

Или зарегистрируйте новый аккаунт (даётся 500 монет).

## Что работает

- Регистрация и вход
- Каталог розыгрышей (с демо-событиями)
- Покупка билетов за монеты
- Автоматический розыгрыш при заполнении
- Баланс и история операций
- Запрос монет
- Создание розыгрышей (для owner/admin)
- Уведомления о победе

Данные хранятся в `standalone/data.sqlite`.
